# RaceGame
Unityの授業用に制作した、Photon Fusionを使用したオンライン対戦レースゲームです。
プレイヤーはジャンプ・ダイビング・パンチを駆使し、コース上の障害物を避けながらゴールを目指します。

ゲームの設計・実装と、その制作過程を説明する教材の作成を行いました。
リポジトリでは、開発で作成したC#スクリプトのみを抜粋しています。

## 主な実装

- ホストのセッション作成と、クライアントとしての参加
- プレイヤーの生成・入力・アクション
- 参加待機・カウントダウン・レース管理・結果表示の進行制御
- ゴール判定、制限時間
- チェックポイントと落下時のリスポーン

ゲームはホストモードで実装しています。
`NetworkManager`が接続を管理し、`GameMainManager`がレース参加プレイヤーとレースの進行を管理します。

クライアントがレース中に退出しても成立するように、`GameMainManager`が毎フレームプレイヤーの生存確認を行い、
退出者のデータとプレイヤーオブジェクトを削除する形で、ゲームが進行するようにしています。
